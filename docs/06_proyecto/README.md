# 06 · Proyecto

Gestión del proyecto y entrega al negocio.

Qué va aquí:

- **Trazabilidad:** requisito → issue → PR → prueba.
- **Actas** de reuniones con el dueño del negocio (fecha, asistentes, acuerdos).
- **Manual de usuario** por rol (mesero, cajero, administrador).
- **Documentos de entrega:** acta de entrega y constancia.

Lo que avanza día a día (tareas, bugs, estado) no se escribe aquí: vive en las issues y milestones de GitHub.
