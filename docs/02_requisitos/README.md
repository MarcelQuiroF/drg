# 02 · Requisitos

Qué tiene que hacer el sistema y con qué reglas.

Qué va aquí:

- **`requisitos.md`:** requisitos funcionales (`RF-xx`), reglas de negocio (`RN-xx`) y requisitos no funcionales (`RNF-xx`). Las historias de usuario de GitHub citan estos códigos.
- **`matriz-brechas.md`:** cada requisito frente al sistema actual: ¿está implementado? ¿funciona?
- **`preguntas-dueno.md`:** dudas que solo el dueño del negocio puede responder, con la respuesta y la fecha cuando se tenga.

Un requisito se marca como **validado** solo cuando lo confirmó el negocio.
